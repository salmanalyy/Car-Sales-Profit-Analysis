# Car Sales & Profit Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze car sales and profit performance.

## Tools Used
- Microsoft Power BI
- DAX
- Data Visualization

## Dashboard Features
- Sales and profit KPI cards
- City-based filtering
- Interactive charts and slicers
- Sales and profit performance analysis
